# Steering System Analysis

## Status
This document records the initial steering-control investigation plan.

## High-priority questions
- What is the steering command source?
- Is the system wheel-based, joystick-based, or both?
- What feedback sensors are present?
- What is the controller output to the steering actuator?
- What safety interlocks or failure responses are implemented?

## Confirmed vs inferred
- Confirmed: information will be recorded only when supported by recovered source files or documentation.
- Inferred: notes will be clearly marked as engineering inference.
- Missing: any absent information should be listed in the outstanding-questions document.
