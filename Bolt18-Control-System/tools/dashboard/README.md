# Bolt 18 Dashboard

This dashboard is a design mock-up for monitoring the original Bolt 18 control system while the CAN analyser is connected and logging traffic.

## Purpose

The dashboard is intended to present:
- steering demand and feedback
- propulsion speed and torque
- battery state and temperature
- CAN bus health
- system safety status
- message feed from the recovered CAN database

## Open locally

Open the file `bolt18-dashboard.html` in a browser or VS Code preview.

## Current status

This is a design baseline and not yet connected to live hardware. It is intended to be adapted to the recovered DBC and real message names as the project is analysed further.
